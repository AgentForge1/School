🔁 Quick Recap: What is Pseudocode?

In Lesson 1, we learned that pseudocode is a text version of an algorithm that looks similar to code but isn't tied to any one programming language.

Good pseudocode should be:

  • Short — only the essential steps
  • Clear — easy to read and understand
  • Precise — no vague instructions
  • Started with START and ended with STOP — always uppercase

🔍 What is a Linear Search?

A linear search (also called a sequential search) is the simplest searching algorithm. It works by checking each item in a list one at a time, in order, from the start, until either:

  • the item you're looking for is found, or
  • you reach the end of the list and the item isn't there.
Key idea: A linear search doesn't skip ahead. It checks every item in turn. This makes it easy to write but slow for large lists.

📝 Worked Example: Searching for "Tiger"

Let's trace a linear search to find the data item 'Tiger' in this list.

Step-by-step trace

  1. Start at index 1: is "Cat" == "Tiger"? No → move to the next item.
  2. Index 2: is "Hamster" == "Tiger"? No → move on.
  3. Index 3: is "Bat" == "Tiger"? No → move on.
  4. Index 4: is "Parrot" == "Tiger"? No → move on.
  5. Index 5: is "Horse" == "Tiger"? No → move on.
  6. Index 6: is "Lion" == "Tiger"? No → move on.
  7. Index 7: is "Tiger" == "Tiger"? Yes! → the item is found at index 7. Stop searching.
Result: "Tiger" is found at index 7. The linear search checked 7 items before finding it.

Pseudocode for a linear search

START items = ["Cat", "Hamster", "Bat", "Parrot", "Horse", "Lion", "Tiger", "Camel", "Bear", "Swan"] target = "Tiger" found = FALSE index = 1 WHILE index <= 10 AND found == FALSE IF items[index] == target THEN found = TRUE ELSE index = index + 1 ENDIF ENDWHILE IF found == TRUE THEN OUTPUT "Item found at index " + index ELSE OUTPUT "Item not found" ENDIF STOP
Notice: The linear search uses a WHILE loop to move through the list and an IF statement to check each item. The loop stops as soon as the item is found — it doesn't keep searching unnecessarily.

❓ Why Are Searching Algorithms Needed?

Searching algorithms are needed because computers store huge amounts of data — far more than a person could check by hand. A searching algorithm gives the computer a reliable, repeatable set of steps to find a specific item quickly and accurately.

Key reasons:

  • Speed — a computer can check thousands of items per second.
  • Accuracy — the algorithm won't miss an item or get distracted.
  • Consistency — the same steps work every time, for any data set.
  • Automation — searches can run without a human watching.
Think about it: If a website has 10 million users and you log in, the computer must find your account among all of them. Without a searching algorithm, that would be impossible.
