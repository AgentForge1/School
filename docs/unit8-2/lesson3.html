🔁 Quick Recap: What is Pseudocode?

Pseudocode is a text version of an algorithm that looks similar to code but isn't tied to any one programming language.

Good pseudocode should be:

  • Short — only the essential steps
  • Clear — easy to read and understand
  • Precise — no vague instructions
  • Started with START and ended with STOP — always uppercase

📡 What is Radio Communication?

Micro:bits can communicate wirelessly using a feature called the radio function. This allows them to send messages, images, or even secret codes to each other — all without using wires!

Key concepts:

  • Radio group (channel) — both micro:bits must be set to the same group to communicate.
  • Radio library — must be imported at the start of the program.
  • Send and receive — one micro:bit sends, the other receives.
Important: The radio group must be unique to your pair. If another pair uses the same group, your messages could be intercepted!
💡 Why This Matters

Real-World Encryption

Encoding is not just a classroom exercise — it is how real-world encryption works. When you send a WhatsApp message, make a bank transaction, or visit a secure website (https), your data is encoded and encrypted so that anyone intercepting it sees meaningless numbers or characters, not your private information.

The alphabet-position encoding you are learning today is a simplified version of the same principle. In fact, the micro:bit radio messages you will send are encoded as numbers — and if someone else's micro:bit picks up your signal, they will see numbers, not words, unless they know your encoding system.

🔐 Encoding Messages with Alphabet Positions

Instead of sending words directly, we can send numbers that represent letters. Each letter has a position in the alphabet:

1234567 8910111213
NOPQRST UVWXYZ
14151617181920 212223242526
Example: "HELLO" = 8, 5, 12, 12, 15

Plenary — Exit Ticket (3 mins)

Let's review what we learned today.

1. What is the radio group used for?

The radio group sets the channel that micro:bits use to communicate. Both micro:bits must have the same group number.

2. Why do we encode messages using numbers?

To keep messages private and secure. If someone intercepts the radio signal, they see numbers, not words.

3. What must be the same on both micro:bits for them to communicate?

The radio group (channel). If they have different groups, they cannot send or receive messages.

4. What is the difference between AND and OR?

AND means both conditions must be true. OR means at least one condition must be true.
