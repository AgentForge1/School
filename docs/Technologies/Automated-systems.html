🔁 What is an Automated System?

An automated system is a system that carries out a task or a series of tasks without the need for a human to be directly involved.

Automated systems are made up of three main parts:

  • Sensors — detect changes in the environment (input).
  • Microprocessor — processes the data from the sensors and decides what to do.
  • Actuators — carry out an action (output), such as moving a robot arm, opening a door or turning on a light.
Key idea: An automated system uses a feedback loop — it senses something, processes it, acts, and then checks again. This lets it keep working correctly without a person watching it.

Example: Automatic doors

You walk up to an automatic door at a supermarket. A microwave sensor detects you are near. The microprocessor decides the door needs to open. An actuator (motor) opens the door. The door waits, then closes when no one is nearby.

Task 3: Greenhouse Lighting Algorithm ★★★ Spicy

Start Timer (10 min) Locked

Read the scenario and write your algorithm in the box below.

The Scenario: A farmer has automated lighting for a greenhouse used to grow lettuces. The lights need to turn on:
  • Between the hours of 4pm and 11pm in the winter
  • Between the hours of 9pm and 11pm in the summer
  • Whenever it is cloudy (light sensor reading less than 5)

(a) Explain three sensors and how they could be used to control a lighting system.

(b) Develop an algorithm using pseudocode or English sentences for the automated lighting system.

💡 Hint: Remember to check the light level first, then use IF/ELSE IF to check the season and the time. Use AND to combine conditions.
Example sensors for lighting: Light sensor (turn on headlights when dark), touch sensor (light switch), microphone (voice-activated lighting), internal clock (timed lighting).

Example pseudocode: 
currentLight ← CALL GetLightValue()
hour ← CALL GetHour()
season ← GetSeason()
lightState ← FALSE

IF currentLight < 5 THEN
    lightState ← TRUE
ENDIF

IF season = "Winter" AND hour >= 16 AND hour <= 23 THEN
    lightState ← TRUE
ELSE IF season = "Summer" AND hour >= 21 AND hour <= 23 THEN
    lightState ← TRUE
ENDIF
