1 Fix the Broken Selection

The following code is supposed to print "Pass" if the score is 50 or above and "Fail" otherwise, but the branches are in the wrong order and one condition is always true. Copy it into the IDE, fix it, and test it with scores of 30, 50, and 90.

score = int(input("Enter score: "))
if score > 50:
    print("Fail")
else:
    print("Pass")
What to do: Fix the comparison so that 50 counts as a pass, and swap the branches so the output is correct. Then test all three scores.
✅ Success criteria: 30 → "Fail", 50 → "Pass", 90 → "Pass".

2 Fix the Wrong Branch Order

The following code is meant to award grades A–F, but "A" can never be printed. Find the bug and fix it.

grade = int(input("Enter grade: "))
if grade >= 60:
    print("D")
elif grade >= 70:
    print("C")
elif grade >= 80:
    print("B")
elif grade >= 90:
    print("A")
else:
    print("F")
What to do: Reorder the elif branches so that the highest threshold is checked first. Test with 95, 85, 75, and 65.
✅ Success criteria: 95 → "A", 85 → "B", 75 → "C", 65 → "D".

3 Range Check with and

Write a Python program that asks the user for a number and prints "In range" if it is between 10 and 20 (inclusive), otherwise prints "Out of range".

⚠️ Watch out: Use and, not or. A condition like x >= 10 or x <= 20 is always true! Ask yourself: does the number need to satisfy both limits at once?
✅ Success criteria: 5 → "Out of range", 10 → "In range", 15 → "In range", 20 → "In range", 25 → "Out of range".

4 Login Check with Logical Operators

Write a program that sets username = "admin" and password = "pass123". Ask the user to enter both, then print "Access granted." only if both match; otherwise print "Access denied."

Hint: Use == for each comparison and combine them with and.
✅ Success criteria: Correct username + correct password → granted. Anything else → denied.

5 Nested Selection — Ticket Price

A cinema charges: $12 for adults (18+), $8 for children (under 18). Students (any age) get $2 off. Write a program that asks for age and whether the customer is a student (y/n), then prints the correct price.

Suggested structure: Use a nested if for the age check, then a separate if (or elif) for the student discount.
✅ Success criteria:
  • Adult, not student → $12
  • Adult student → $10
  • Child, not student → $8
  • Child student → $6

6 Trace the Selection

Without running the code, work out which message is printed for each input. Fill in the trace table below, then click Check. Verify in the IDE using the Step button.

score = int(input("Score: "))
is_member = input("Member? (y/n): ") == "y"

if score >= 80 and is_member:
    print("Gold discount")
elif score >= 80 or is_member:
    print("Silver discount")
else:
    print("No discount")

💡 Think about it: In the second row, score >= 80 is True but is_member is False, so the and condition is False. The or condition is True — which is why "Silver discount" is printed. This is the key to understanding how and/or interact.

💡 Key Takeaway

"Selection structures let your program make decisions. The condition must be written correctly, the branches must be in the right order, and the logic must match your intention. Test each branch — every path through your if/elif/else chain should be checked with real values."
